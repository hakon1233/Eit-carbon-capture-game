2 Stats Aggregation System

Overview

When countries combine into regions or continents, their stats are aggregated using context-specific weighting methods.

File: climate-data.js → aggregateCountriesToRegion()

Aggregation Methods by Statistic

Statistic Method Rationale
Population SUM Total people in region
GDP SUM Total economic output
Total Emissions SUM Total CO2 output
Per Capita Emissions Calculated totalEmissions / totalPopulation
Emissions Trend Emissions-weighted Higher emitters have more impact
Emission Sources Emissions-weighted Sector breakdown by who emits most
Solar/Wind Potential Population-weighted Proxy for land area
Forest/Geothermal Simple average Location-specific resources
Carbon Capture GDP-weighted Requires infrastructure investment
Climate Finance GDP-weighted Larger economies = more policy impact
Base Income SUM Total budget contribution

Weighted Average Formulas

Emissions-weighted:

result = Σ(value[i] × emissions[i]) / totalEmissions

GDP-weighted:

result = Σ(value[i] × gdp[i]) / totalGdp

Population-weighted:

result = Σ(value[i] × population[i]) / totalPopulation

Why Different Weights?

  • Emissions trend: China's 1% change matters more than Malta's 1% change
  • Solar/Wind: Large countries have more installable capacity
  • Carbon Capture: Requires industrial infrastructure (GDP proxy)
  • Climate Finance: Policy decisions scale with economic power
3 Climate Model

Temperature Calculation

Global Temperature:

temperature = (CO2 - 280) × 0.008°C

280 ppm is the pre-industrial CO2 baseline. Climate sensitivity is 0.008°C per ppm.

CO2 (ppm) Temperature Status
405+1.0°CWIN
420+1.12°CStarting
467+1.5°CTipping Point 1
530+2.0°CTipping Point 2
655+3.0°CLOSE

Monthly CO2 Change

newCO2 = currentCO2 + baseIncrease + feedbackEffects - projectReductions
Component Value Source
Base Increase 0.3-0.7 ppm/month Difficulty setting
Feedback Effects Variable Tipping points + loops
Project Reductions Sum of active projects Player actions

Climate Feedback Loops

Gradual amplification effects that worsen as climate deteriorates:

Feedback Trigger Effect
Ice-Albedo ≥1.5°C Melting ice reduces reflectivity
Ocean Saturation ≥450 ppm Warmer oceans absorb less CO2
Vegetation Stress ≥2.0°C Heat-stressed plants absorb less

Regional Temperature

regionalTemp = globalTemp × regionalMultiplier

Regional multipliers account for differential warming (e.g., Arctic warms faster).

Regional Effectiveness

Each region has potential scores (0-1) that modify project costs and effects:

Adjusted Cost:

cost = baseCost × (2 - potentialScore)

Adjusted Effect:

effect = baseEffect × potentialScore

Example: Solar in Saudi Arabia (potential 0.95):

  • Cost: $10B × (2 - 0.95) = $10.5B
  • Effect: 1 ppm × 0.95 = 0.95 ppm reduction

Solar in Norway (potential 0.3):

  • Cost: $10B × (2 - 0.3) = $17B
  • Effect: 1 ppm × 0.3 = 0.3 ppm reduction

Technology Multipliers

Unlocked technologies modify base project stats:

effectiveEffect = baseEffect * potentialScore * techMultiplier
effectiveCost = baseCost * (2 - potentialScore) * techCostMultiplier
5 Income System

Monthly Income Calculation

monthlyIncome = (GDP × climateDedication%) / 12

Each country contributes based on their GDP and climate dedication percentage.

Climate Dedication Parameters

Parameter Description Typical Range
currentPercent Current % of GDP dedicated 0.5% - 3%
maxPercent Maximum achievable % 3% - 7%
minPercent Minimum floor % 0.3% - 1%
difficulty Political difficulty multiplier 0.2 - 1.0
politicalResistance Campaign time multiplier 0.2 - 1.0

Climate Policy Campaigns

Campaigns increase a country's currentPercent:

Campaign Cost:

cost = GDP × 0.5% × difficulty

Campaign Duration:

months = 12 × difficulty × politicalResistance

Dedication Increase:

increase = 0.3% per successful campaign

Income Sources

  1. Country Contributions: GDP × dedication %
  2. Project Income: Active projects (Solar, Wind, Nuclear)
  3. Event Modifiers: Can boost or reduce income temporarily

Event Structure

{
  id: "heat_wave",
  name: "Severe Heat Wave",
  category: "climate",
  duration: 3,              // months
  probability: 0.05,        // 5% per month
  effects: {
    incomeMultiplier: 0.9,  // -10%
    projectEfficiency: 0.85 // -15%
  },
  conditions: {
    minTemperature: 1.5     // only triggers above 1.5C
  }
}

Event Processing

  1. Check if conditions are met (temperature, date, etc.)
  2. Roll probability each month
  3. If triggered, apply effects for duration
  4. Decrement duration each month until 0
  5. Remove event when expired

9 Game Loop

Monthly Tick Sequence

Function: advanceMonth() in game.js

  1. 1Time Advance: Increment month (wrap year at 13)
  2. 2CO2 Increase: Add base + feedback effects
  3. 3Projects Process: Calculate reductions and income
  4. 4CO2 Reduce: Subtract project reductions
  5. 5Temperature Update: Recalculate from CO2
  6. 6Tipping Points: Check and trigger if threshold crossed
  7. 7Events Process: Tick active events, maybe trigger new
  8. 8Research Points: Add RP from Research Centers
  9. 9Campaigns: Progress active campaigns
  10. 10Income: Add country + project income
  11. 11Achievements: Check unlock conditions
  12. 12Win/Lose Check: Test victory/defeat conditions
  13. 13Auto-Save: Persist to localStorage

Stats Helper Functions

// Calculate net CO2 rate per month
function calculateNetCO2Rate() {
  let rate = DIFFICULTY_SETTINGS[state.difficulty].co2Rate;
  // Add project reductions (negative values)
  Object.values(state.regions).forEach(region => {
    region.projects.forEach(proj => {
      const project = PROJECT_TYPES[proj.type || proj];
      if (project) rate += project.co2Effect * (proj.effectMultiplier || 1);
    });
  });
  // Add feedback effects
  rate += getTotalClimateFeedback();
  return rate;
}

// Count total projects across all regions
function countTotalProjects() {
  let count = 0;
  Object.values(state.regions).forEach(r => count += r.projects.length);
  return count;
}

// Count active disasters globally
function countActiveDisasters() {
  let count = 0;
  Object.values(state.activeDisasters || {}).forEach(d => count += d.length);
  return count;
}
