# Nice-to-Have Features

Lower priority features to implement if time allows (Phase 4-5 from project plan).

---

## Phase 4: Polish & Engagement

### Visual Upgrades
- [ ] Animated world map (subtle movement, breathing effect)
- [ ] Weather particle effects (rain, snow, storms)
- [ ] Day/night cycle across map
- [ ] Seasonal changes (vegetation colors)
- [ ] Project construction animations
- [ ] CO2/temperature change visual effects
- [ ] Region pulse effects on events

### Achievement System
- [ ] Achievement tracking and unlock notifications
- [ ] Achievement categories:
  - **First Steps** - Build your first project
  - **Solar Revolution** - 10 solar farms in one region
  - **Forest Guardian** - Reforest 5 continents
  - **Speed Runner** - Win before 2050
  - **Global Coalition** - Projects in all regions
  - **Climate Hero** - Win on Hard difficulty
  - **Scientist** - Unlock all tech tree items
  - **Zero Carbon** - Reach net-zero emissions
- [ ] Achievement display panel
- [ ] Progress tracking for multi-step achievements

### Difficulty Modes
- [ ] **Easy** - More starting credits, slower CO2 increase, forgiving thresholds
- [ ] **Normal** - Current balanced settings
- [ ] **Hard** - Less credits, faster warming, stricter win conditions
- [ ] **Realistic** - Based on actual IPCC projections and timelines
- [ ] Difficulty selector on launch screen
- [ ] Different win/lose thresholds per difficulty

### Educational Content
- [ ] Toggleable fact popups during gameplay
- [ ] Climate glossary (CO2, ppm, greenhouse effect, etc.)
- [ ] "Learn More" links to real climate resources
- [ ] Quiz mode between game sessions
- [ ] Teacher mode with curriculum integration
- [ ] Printable fact sheets

### Sound & Music
- [ ] Background ambient music (calm, atmospheric)
- [ ] UI sound effects (button clicks, notifications)
- [ ] Event sound effects (alerts, achievements)
- [ ] Project construction sounds
- [ ] Win/lose music
- [ ] Volume controls and mute option

## Phase 5: Advanced Features

### Scenario Challenges
Pre-built challenges with unique starting conditions:
- [ ] **The Oil Crisis** - Start with high fossil fuel dependency
- [ ] **Island Nations** - Focus on vulnerable coastal regions
- [ ] **The Billionaire** - Unlimited credits but political resistance
- [ ] **Deadline 2050** - Accelerated timeline challenge
- [ ] **Cooperation Required** - Must build projects in every region
- [ ] **The Skeptic** - Low public support everywhere
- [ ] **Rising Seas** - Sea level rise as additional threat
- [ ] Scenario selector and descriptions
- [ ] Unique win conditions per scenario

### Multiplayer
- [ ] **Competitive mode** - Players compete for best climate outcome
- [ ] **Cooperative mode** - Players manage different regions together
- [ ] Turn-based multiplayer
- [ ] Real-time multiplayer option
- [ ] Lobby system and matchmaking
- [ ] Player stats and leaderboards

### Real Data Integration
- [ ] Import real IPCC climate projections
- [ ] Live CO2 data from monitoring stations
- [ ] Historical temperature data comparison
- [ ] "What if" scenarios based on real policies
- [ ] Data source citations and links

### Sandbox Mode
- [ ] Unlimited credits for experimentation
- [ ] Adjustable game parameters
- [ ] No win/lose conditions
- [ ] Fast-forward time controls
- [ ] Reset individual regions
- [ ] Export game state for sharing

### Save/Load System
- [ ] Local save to browser storage
- [ ] Multiple save slots
- [ ] Auto-save feature
- [ ] Cloud save sync (requires backend)
- [ ] Export/import save files
- [ ] Resume from last session prompt

## Implementation Notes

These features would significantly enhance the game but are not required for core gameplay. Consider implementing them after Phase 2-3 features are stable.

**Suggested order if time allows:**
1. Sound & Music (high engagement impact, moderate effort)
2. Achievement System (replayability)
3. Difficulty Modes (accessibility)
4. Save/Load (quality of life)
5. Educational Content (mission alignment)
6. Visual Upgrades (polish)
7. Scenario Challenges (content)
8. Sandbox Mode (experimentation)
9. Real Data Integration (authenticity)
10. Multiplayer (highest effort)
