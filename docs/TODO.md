# Features To Implement

This document tracks features that need to be implemented (Phase 2-3 from project plan).

## Phase 2: Core Improvements

### Random Events System
- [ ] News ticker with scrolling events
- [ ] Event categories:
  - **Natural disasters** - Floods, droughts, hurricanes affecting regions
  - **Political events** - Elections, policy changes, international agreements
  - **Scientific breakthroughs** - Research discoveries reducing costs
  - **Economic events** - Market crashes, booms, funding changes
- [ ] Events affect gameplay (costs, effectiveness, regional stats)
- [ ] Event frequency balancing

### Project Upgrade System
- [ ] Branching upgrade paths for each project type
- [ ] **Forest upgrades**:
  - Forest Lv1 → Forest Lv2 → Ancient Forest
  - Forest Lv1 → Mangrove Forest (coastal regions)
  - Forest Lv1 → Urban Forest (city regions)
- [ ] **Solar upgrades**:
  - Solar Lv1 → Solar Lv2 → Solar Mega-Farm
  - Solar Lv1 → Floating Solar (water regions)
- [ ] **Research upgrades**:
  - Research Lv1 → Advanced Lab → Breakthrough Center
- [ ] Upgrade UI in region panel
- [ ] Upgrade costs and prerequisites

### Expanded Region Detail Panel
- [ ] Population mood/happiness indicator
- [ ] Special regional bonuses display
- [ ] More detailed local climate stats
- [ ] Historical data graphs (temperature/emissions over time)

## Phase 3: Depth & Strategy

### Tech Tree System
- [ ] Visual tech tree UI
- [ ] Unlock advanced projects through research:
  - **Carbon Capture Plant** - High CO2 reduction, expensive
  - **Ocean Seeding** - Ocean-based CO2 absorption
  - **Clean Energy Grid** - Regional electricity transformation
  - **Climate Education** - Reduces regional resistance
  - **Green Hydrogen** - Clean fuel production
  - **Smart Grid** - Efficiency improvements
  - **Direct Air Capture** - Advanced carbon removal
- [ ] Research point requirements for unlocks
- [ ] Tech tree dependencies (prerequisites)

### Political Support System
- [ ] Regional support meters (0-100%)
- [ ] Support affects:
  - Project costs (low support = higher costs)
  - Available project types (some require high support)
  - Event outcomes
- [ ] Ways to increase support:
  - Building popular projects
  - Education campaigns
  - Economic benefits from green projects
- [ ] Ways support decreases:
  - Unpopular projects
  - Economic disruption
  - Ignoring regional needs

### Multiple Resource Types
- [ ] **Research Points** - Generated by Research Labs, spent on tech tree
- [ ] **Influence** - Used for political actions and negotiations
- [ ] **Materials** - Required for large construction projects
- [ ] Resource UI in top bar
- [ ] Resource generation from projects
- [ ] Resource spending mechanics

### Advanced Project Types
Once unlocked via tech tree:
- [ ] **Offshore Wind** - Ocean regions, high output
- [ ] **EV Infrastructure** - Reduces transport emissions
- [ ] **Sustainable Agriculture** - Reduces food sector emissions
- [ ] **Nuclear Plant** - High output, controversial (support impact)
- [ ] **Carbon Capture Facility** - Industrial CO2 capture
- [ ] **Direct Air Capture** - Atmospheric CO2 removal
- [ ] **Green Hydrogen Plant** - Clean fuel production
- [ ] **Smart Grid** - Regional efficiency boost

---

## Priority Order

1. Random events (adds variety and replayability)
2. Project upgrade system (adds progression)
3. Tech tree (strategic depth)
4. Political support (meaningful choices)
5. Multiple resources (economic complexity)
6. Advanced projects (content expansion)
